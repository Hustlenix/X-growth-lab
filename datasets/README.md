# 📊 X Growth Lab: Datasets

## Introduction
The Datasets layer provides the raw data and benchmarks used to power the Lab's tools and frameworks. This allows creators to compare their performance against real-world success metrics rather than guessing.

## Current Datasets
*Note: Datasets are currently being populated. Check back soon for updates!*

### 1. Benchmark Engagement Rates
A collection of average engagement rates categorized by account size and niche. This will power the `engagement-score.py` tool for more accurate predictions.

### 2. High-Performing Hooks
A library of 1,000+ successful hooks analyzed for their "curiosity gap" and conversion potential. This dataset feeds the `hook-generator.py`.

### 3. Algorithm Signal Weights
Documented weights for different interaction types (Likes vs. Bookmarks vs. Replies) derived from open-source algorithm analysis.

## How to Contribute
If you have anonymized data from high-performing accounts, please see `CONTRIBUTING.md` to help us build the most accurate open-source growth dataset.
