# 📊 X Growth Lab Datasets

This directory is dedicated to the data layer of the X Growth Lab.

## Purpose
While the tools in this repository use heuristics to provide immediate value, the datasets serve as the "ground truth" for understanding how the X algorithm treats different types of content.

## Current Datasets
- *Coming Soon*: Sample high-performance hooks and their metrics.
- *Coming Soon*: Categorized engagement signal weights based on public platform engineering blogs.

## How to use with Tools
The heuristics in `tools/post-analyzer.py` and `tools/engagement-score.py` are derived from the analysis of these datasets. As the community contributes more data, these tools will become increasingly accurate.
