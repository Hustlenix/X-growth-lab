# Contributing to X Growth Lab

Thank you for your interest in contributing! We want to make this the best beginner-friendly resource for understanding X, and we need your help to do that.

---

## 🚦 How to Get Started
1. **Browse Issues:** Look for "good first issue" or open a new one to discuss your idea.
2. **Fork & Clone:** Create your own copy of the repository.
3. **Branching:** Create a descriptive branch name (e.g., `feature/new-case-study` or `fix/typo-in-algorithm`).

## 📝 Issue Reporting Guidelines
- **Use Templates:** If available, use the provided issue templates.
- **Be Specific:** Describe exactly what is wrong or what you want to add.
- **Reference Sources:** If reporting an inaccuracy about the algorithm, please provide a link to the source or research.

## 📚 Documentation Standards
To maintain consistency and educational quality, all new documentation must follow this structure:
1. **Introduction:** High-level overview.
2. **Core Concepts:** Detailed explanation + "Why it matters" callouts.
3. **Visuals:** At least one Mermaid diagram or table.
4. **Common Beginner Mistakes:** Practical pitfalls to avoid.
5. **Practical Applications:** Actionable steps.
6. **Mini Exercise:** A small task for the reader.
7. **Summary & Key Takeaways:** A TL;DR of the guide.
8. **Related Reading:** Links to other internal docs.

## 🏷 Naming Conventions
- **Files:** Use `kebab-case` for all markdown files (e.g., `ranking-signals.md`).
- **Assets:** Store any images in a `static/` directory (if applicable).
- **Headings:** Use Sentence case for headings.

## ✅ Pull Request Checklist
Before submitting a PR, ensure you have:
- [ ] Checked for broken internal links.
- [ ] Followed the Documentation Standards (if adding/editing docs).
- [ ] Run a spell check on all new text.
- [ ] Added a clear description of the changes in the PR body.
- [ ] Ensured the PR is focused (one major change at a time).

## 👀 Review Expectations
- **Tone:** Be helpful and encouraging in reviews.
- **Accuracy:** We prioritize correctness over speed.
- **Beginner-Friendliness:** If a concept is too complex, we may ask for a simplified explanation or more examples.
